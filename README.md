# La web que nos cambió

Sitio web estático sobre el **impacto de las tecnologías web en la sociedad y los negocios**, hecho con HTML5 y CSS
para la Actividad Práctica 1 de la asignatura Tecnologías Web (UTPL, primer bimestre, octubre 2026 - febrero 2027).

## Cómo verlo

- En línea (GitHub Pages): https://dathorfa.github.io/tecweb-impacto-web/
- En la computadora: descargar o clonar el repositorio y abrir `index.html` con cualquier navegador.
  No necesita servidor ni instalar nada.

## Estructura

```
index.html                 Inicio: evolución de la web, cómo funciona HTTP, video y estructura del sitio
css/estilos.css            Hoja de estilos única para todas las páginas
img/                       Logotipo y figuras (SVG, PNG y JPG, elaboración propia)
video/                     Video corto del sitio (MP4, 30 s, sin audio)
pages/sociedad.html        Impacto en la sociedad (tabla 1)
pages/negocios.html        Impacto en los negocios (tabla 2)
pages/caso-practico.html   Caso práctico de una empresa ecuatoriana
pages/contacto.html        Formulario de contacto con validación HTML5
pages/gracias.html         Confirmación del envío del formulario
pages/referencias.html     Referencias en formato APA 7
```

## Qué se aplicó

- Etiquetas semánticas: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure` y `figcaption`.
- Encabezados `h1` a `h6`, párrafos, listas ordenadas, no ordenadas y de definición, y dos tablas.
- Siete figuras con texto alternativo y un video local con `controls` y `poster`.
- Formulario con `form`, `fieldset`, `label`, `input`, `select`, `textarea` y `button`.
- Menú igual en todas las páginas y rutas relativas en todos los enlaces internos.
- Las siete páginas pasan el validador del W3C (https://validator.w3.org/nu/) sin errores ni advertencias.
